# 📊 HR Analytics Dashboard

An interactive **HR Analytics Dashboard** created as a data analytics project to analyze employee information, workforce trends, and key HR performance indicators.

> **Note:** This is a personal/practice project created using **sample CSV data**. The dataset does not represent any real company or real employees.

## 🚀 Project Overview

The **HR Analytics Dashboard** provides a visual overview of employee-related data and helps identify important HR trends through interactive KPIs, charts, and filters.

The project was created to practice **data cleaning, data analysis, KPI creation, and dashboard development** using a sample HR dataset.

## 📂 Dataset

The dashboard uses **sample CSV data** containing fictional employee records.

The dataset includes fields such as:

* Employee ID
* Employee Name
* Department
* Job Role
* Gender
* Age
* Joining Date
* Experience
* Salary
* Employment Status
* Performance Rating
* Attendance
* Leave Balance
* Training Status
* Location
* Insurance Status
* License/Document Status

## 📌 Key KPIs

The dashboard includes the following important HR KPIs:

| KPI                              | Description                                  |
| -------------------------------- | -------------------------------------------- |
| 👥 **Total Employees**           | Total number of employees in the dataset     |
| 🏢 **Total Departments**         | Number of departments                        |
| 💰 **Average Salary**            | Average salary of employees                  |
| 📈 **Average Experience**        | Average employee experience                  |
| ⭐ **Average Performance Rating** | Average performance score                    |
| 🚪 **Attrition Rate**            | Percentage of employees who left             |
| 🟢 **Active Employees**          | Number of currently active employees         |
| 📅 **Average Attendance**        | Average employee attendance                  |
| 🎓 **Training Completion Rate**  | Percentage of employees completing training  |
| 🏥 **Insurance Coverage**        | Percentage of employees covered by insurance |
